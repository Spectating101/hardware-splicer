## Owner-intervention policy

Do not ask the project owner to make decisions that can be determined from rules, evidence or package doctrine.

Ask only for genuinely non-delegable actions such as:

- logging into a submission portal;
- providing legal identity/contact fields that are not already available and should not be guessed;
- uploading student enrollment proof;
- selecting/confirming a faculty adviser when required;
- paying a registration fee or authorizing travel;
- supplying an API credential through a secure channel;
- conducting/recording real physical bench work.

Everything else should be prepared from the canonical package.
