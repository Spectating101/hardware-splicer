# 30-Second Demo

## Goal

Make the evaluator understand the problem and differentiation before seeing architecture detail.

## Script

**0–10 seconds — problem**

> AI-generated hardware can look convincing long before it is safe to fabricate.

Show one project state containing an unresolved or conflicting hardware fact.

**10–20 seconds — behavior**

> Hardware-Splicer lets the AI reason about the engineering problem, but component identity, evidence, electrical constraints and revision state remain independently auditable.

Show the model proposal beside a deterministic blocker/unresolved state.

**20–30 seconds — authority boundary**

> The AI can propose. It cannot declare its own output physically safe. Real bench evidence must be tied to the exact revision, and authorization remains human.

End on:

> **AI proposes → deterministic systems constrain → bench evidence decides → human authorizes.**

## What not to show

Do not spend this slot on repository size, test counts, generic chat UI, model branding or long architecture diagrams.
