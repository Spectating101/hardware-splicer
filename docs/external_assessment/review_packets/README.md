# Independent claim-review packets

`2026-09-12-primary-source-claims-v1.json` was derived from canonical revision 3 of the
published Milestone A project. It contains the 11 source identities, document revisions,
hashes, locators, and paraphrases, but excludes Astra's candidates, decisions, and
conclusions.

The reviewer should obtain the exact source bytes, verify their SHA-256 identities, inspect
each locator, and record one of `SUPPORTED`, `PARTIAL`, `WRONG`, or `AMBIGUOUS`, plus any
correction. Reviewer identity and review date must be supplied. Completing this packet does
not establish electrical correctness, physical identity, fabrication readiness, or physical
authority.

The project assurance review endpoint can persist completed results as a new canonical
revision. It deliberately leaves independent signoff and all physical authority closed.
