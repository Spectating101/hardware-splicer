# Research Access Conversion — Execution Board (2026 Q3)

This is the operational layer for firing the research/resource routes. It should be updated with receipts, decisions and exact live-form changes.

## Release rule

A route is not “ready” merely because its narrative is strong. Promotion requires the packet, current eligibility, live form map, evidence state and applicant authority to agree.

Use these meanings consistently:

- **FIRE NOW** — packaging is substantively complete; only live-form transcription/current facts remain.
- **FIRE AFTER GATE** — strong fit, but a named external or experimental dependency must close first.
- **RESEARCH ONLY / HOLD** — do not spend application effort beyond maintaining current facts.

## Canonical receipt fields

For every fired route preserve:

- provider/program;
- exact application URL;
- submitted timestamp/timezone;
- applicant identity/affiliation used;
- project title used;
- packet commit SHA;
- protocol/corpus/evaluator revision where relevant;
- uploaded/entered text snapshot;
- model/budget plan used;
- confirmation number/email/screenshot;
- expected decision cadence/date;
- follow-up date;
- decision;
- resource/affiliation actually received;
- activation/expiry terms if credits are awarded;
- downstream evidence produced using the resource.

## Definition of conversion

A packet is not a conversion.

The progression is:

`eligible → packaged → live-form verified → submitted → receipt → external response → selected/awarded/accepted → resource used → new external evidence`

Keep each state separate in Gauntlet/Blowback.
