## Form copy

### 100-word project introduction

Hardware-Splicer is a model-independent environment for bounded AI-assisted hardware engineering. A general-purpose AI agent can reason, inspect evidence and operate engineering workflows through MCP, while deterministic constraints, provenance-bearing evidence, exact project revisions and scoped human authorization remain independently authoritative. The system currently exposes 193 canonical backend operations through its MCP gateway and includes a frozen ten-case adversarial SPI-flash evaluation corpus. Rather than promising an infallible AI engineer, Hardware-Splicer is designed so that unsupported or wrong model output cannot silently acquire fabrication, power-on or physical-release authority.

### Innovation

The innovation is not merely using generative AI to produce hardware artifacts. Hardware-Splicer makes the model replaceable and treats engineering evidence, revision state and physical authority as first-class system structures outside the model. This enables replayable agent behavior and creates a measurable boundary between semantic reasoning quality and the right to act in the physical world.

## Evidence language

Allowed:

- frozen ten-case adversarial corpus exists and validates;
- real MCP stdio/HTTP sessions work;
- canonical stateful project operations work over MCP;
- 193 canonical operations are exposed;
- external-agent proof infrastructure works;
- MCP cannot grant physical authority by itself.

Not allowed yet:

- “GPT-5.6 passed the unseen corpus”;
- “SPI adapter is physically validated”;
- “independent users successfully completed the workflow”;
- “production ready.”
