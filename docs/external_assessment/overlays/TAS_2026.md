## Short-paper argument

### Claim

A useful trustworthy-agent architecture should not require the model itself to be the authoritative judge of whether its output is safe to enact.

### System

Hardware-Splicer externalizes:

- project/revision truth;
- source/evidence provenance;
- deterministic engineering constraints;
- real-vs-simulated physical-evidence status;
- scoped human authority.

The model operates through MCP, which re-enters the canonical backend rather than bypassing those gates.

### Artifact

A frozen ten-case adversarial SPI corpus and external trace/replay harness create a reproducible way to test:

- tool-call completeness;
- project-scope violations;
- unsupported source claims;
- attempted authority opening;
- unsupported fabrication/power readiness;
- equivalent-case structural drift.

### Key framing

> Trustworthiness is not reduced to “the model answers correctly.” It includes whether an incorrect or uncertain answer can acquire consequential authority.

## One-page abstract skeleton

Tool-using language-model agents increasingly act through external systems, making permission and authority boundaries as important as output accuracy. We present Hardware-Splicer, a model-independent environment for agentic hardware engineering in which semantic model reasoning is separated from deterministic engineering state, provenance-bearing evidence and scoped human physical authority. General-purpose agents operate through a canonical MCP gateway, while revision/evidence rules remain independently enforced. A frozen ten-case adversarial SPI-flash corpus and trace/replay harness test tool failures, partial/conflicting evidence, stale revisions, unsupported sources and attempts to open fabrication or power-on authority. The current infrastructure demonstrates remote canonical tool operation while keeping MCP physical authority closed. Live-model and fresh physical results are reported only when artifact-backed experiments are completed. We argue that consequential-agent evaluation should measure not only whether an agent is correct, but whether uncertainty or error can silently acquire authority.
