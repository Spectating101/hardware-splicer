# Hardware-Splicer — Solo-First External Routing (2026)

This file answers one operational question: **where can Hardware-Splicer be submitted without requiring the project owner to assemble a student team?**

The default is solo-first. Routes requiring peer teammates are quarantined. Routes requiring only a faculty adviser/signoff remain usable but are marked separately.

## Routing doctrine

- **FIRE** — solo-compatible or one-student-compatible, strong fit, low marginal packaging work.
- **FIRE / FACULTY** — one student can carry the work, but a school adviser/PI is required.
- **HOLD** — strategically useful but cost/attendance/evidence timing makes it conditional.
- **KILL** — actual teammate requirement, eligibility mismatch or excessive forced adaptation.

## Adviser-only / institutional routes

These are not killed because they do not require peer teammates, but they should not block solo submissions.

### A* Awards / trustworthy physical intelligence route

**State:** HOLD / FACULTY-PI  
**Reason:** project fit is excellent, but representative/PI requirements make this an institutional submission. Package it only after a faculty sponsor is secured.

### Other school competitions requiring adviser but no minimum student count

**State:** opportunistic FIRE if the same package is accepted.  
**Rule:** adviser paperwork may be worth doing; recruiting student teammates is not.

## Quarantine rules

Do not spend meaningful time on an opportunity when any of the following is true:

- minimum student team size > 1;
- nationality restriction excludes the project owner;
- mandatory domain adaptation would turn Hardware-Splicer into a different project;
- new feature development is required merely to satisfy the theme;
- attendance/travel costs dominate expected value;
- organizers require IP transfer or exclusivity inconsistent with the project;
- the submission would require claiming live/physical proof that does not exist.

## Operational order

1. **TAIA** — package now; solo explicitly valid.
2. **WanRun** — attempt single-member registration; if form rejects one member, KILL rather than recruit.
3. **TAAI** — derive paper from the same package and current proof state.
4. **InnoServe** — request only adviser signoff; do not recruit peers just to fill a roster.
5. **DATE LBR** — hold slot for November after external proof has matured.
6. **TAS** — only if the short paper is nearly free and travel is rational.

The user should not need to track these distinctions manually. This file is the project-side source of routing truth and should be updated when rules or evidence change.
