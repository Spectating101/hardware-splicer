# P216 Desktop robot manual tool coupling

Manual coupler with 3.2 mm hook engagement and 0.355 mm geometry-only tip drift at 70 mm reach.

[Candidate SVG](trial.svg) · [Rejected SVG](rejected.svg) · [Editable dimensions](../designs.json) · [Replay results](../results.json)

## Setup

Use one round locator and one relieved locator at 32 mm separation, with 4 mm pins. Fit the two identical plain tool plates to the key. Use a positive latch with visible closed indicator and a latch spring returning to the seated position. The 66 × 46 mm wrist-side face is an interface blank. Set the horn pattern from the owner's arm, preferably by transferring a sacrificial plate in the current wrist mount. The drift bound covers locator clearance and geometry. [SO-ARM100/101 source CAD](https://github.com/TheRobotStudio/SO-ARM100/tree/main/STEP/SO101)

## Negative control

A 4.6 mm primary seat lets the tool-tip estimate rise to 1.12 mm. The 4.12 mm primary seat holds the bound to 0.36 mm.

## Physical acceptance

Bench-check the closed indicator and both index positions. Use a restrained 100 g dummy tool over a pad and measure the static tip position through 100 cycles. Check that finger force alone can release the latch after unloading.

The catalog models a 25-sale result of NT$ -367.50 at its proposed price. Use the fixture trial and physical acceptance costs to decide whether reuse is economical for the actual job.
