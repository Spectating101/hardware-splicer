# Digital engineering package — no fabrication or powered testing

All contour trays, mounting guides and probe guides in this archive are software-generated, unassembled models. They are **not** approved to be printed, machined, installed or used to energize devices. The Oasis signal probe guide is an *unpopulated-board reference* and does not include assembled ICs, connector heights, operator safety, controlled alignment or verified pogo force. The Protolux M3 hole revision retains an M2.5 footprint library mismatch (four additional warnings) and remains under explicit fabrication hold. Note that STEP files can vary in raw serialization while geometrically identical. Source licences accompany each case; exact source Git revisions and input hashes remain frozen in cases.lock.json and receipts. No physical claims.
